# 🍅 Tomato: A Food Delivery App

Tomato is a full-featured, responsive food delivery application built using the **MERN** stack (MongoDB, Express, React, Node.js) with **Stripe** payment integration. It offers a seamless experience for customers, admins, and delivery personnel by combining a user-friendly frontend, robust backend, and intuitive admin panel.

## 🚀 Features

### 👥 Customer Interface
- **Responsive UI**: Adapts to mobile, tablet, and desktop screens.
- **Authentication**: Secure login & registration via JWT.
- **Restaurant & Menu Browsing**: Filter by category, popularity, or dietary preference.
- **Order Tracking**: Real-time status updates from order placement to delivery.
- **Payment**: Secure Stripe integration for hassle-free transactions.

### 🛠 Admin Panel
- **Manage Users**: View and control customer and delivery staff data.
- **Restaurant/Menu Control**: Add, update, or remove restaurants and items.
- **Track Orders**: Monitor and update order statuses.
- **Analytics Dashboard**: Get insights into user behavior and popular items.

### ⚙️ Backend
- **RESTful API**: Built using Express for data management and authentication.
- **MongoDB**: Stores users, orders, menu items, etc.
- **WebSockets**: Push real-time updates to the UI.
- **Security**: Protected routes, encrypted data, secure payments.
